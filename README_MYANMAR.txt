My Bank နှင့် My Pay — Android Demo Starter

ဤ ZIP တွင် သီးခြား APK ၂ ခု ထုတ်နိုင်သော Android project ပါဝင်သည်။
- My Bank: ငွေလက်ကျန်၊ ငွေသွင်း/ထုတ်၊ ငွေလွှဲ (စမ်းသပ်မှတ်တမ်းသာ)
- My Pay: QR စမ်းသပ်မျက်နှာပြင်၊ ပေးချေမှုမှတ်တမ်း (စမ်းသပ်မှတ်တမ်းသာ)

အရေးကြီး:
- ဤအက်ပ်များသည် DEMO ဖြစ်ပြီး တကယ့်ဘဏ်၊ တကယ့်ငွေလွှဲ၊ QR ငွေပေးချေမှု မလုပ်နိုင်ပါ။
- PIN၊ ဘဏ်စကားဝှက်၊ OTP၊ ကတ်နံပါတ်တို့ကို မထည့်ပါနှင့်။
- တကယ့်ငွေပေးချေမှုအတွက် လိုင်စင်ရဝန်ဆောင်မှုပေးသူ၏ ခွင့်ပြုထားသော API နှင့် လုံခြုံရေးစစ်ဆေးမှုများ လိုအပ်သည်။

APK ထုတ်ရန်:
1. ZIP ကို ဖြည်ပါ။
2. GitHub repository အသစ်တစ်ခုဖန်တီးပြီး ဖိုင်အားလုံး upload လုပ်ပါ။
3. GitHub ရှိ Actions tab > "Build My Bank and My Pay APKs" > Run workflow ကိုနှိပ်ပါ။
4. အလုပ်ပြီးလျှင် Artifacts မှ APK ZIP ကို download လုပ်ပါ။
5. ZIP ဖြည်ပြီး mybank-debug.apk နှင့် mypay-debug.apk ကို Android တွင် စမ်းသပ်တပ်ဆင်ပါ။

GitHub Actions သည် အင်တာနက်နှင့် GitHub account လိုအပ်သည်။
